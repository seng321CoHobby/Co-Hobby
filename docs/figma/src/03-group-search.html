Prototype notes — Screen 03 · US-03 / UC-03

  • Search: GET /groups?category=Music&seekingRole=Drummer (listAvailableGroups), public.
  • Filter options come from GET /tags (Music, Short Film, …). category is required, seekingRole optional.
  • Row fields from GroupListingResponse: groupName, description, category, neededRoles, members.
  • Open role = an entry in neededRoles not yet taken by a member's skillRole. The owner's role is creatorSkillRole.
  • 200 [] → empty state. 400 → inline field error plus Problem message.
  • "View group" → Screen 04, using the same listing item (no separate group-detail endpoint). Group names are sample data.
