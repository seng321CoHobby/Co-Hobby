Prototype notes — Screen 01 · US-07 / UC-05

  • Data: GET /feed/projects (getSharedProjectsFeed), public, no token.
  • Each row shows ProjectResponse fields only: title, description, progressStage (always COMPLETED), isShared.
  • Empty array → empty state shown above. 400 → generic error message.
  • Projects carry no media field, so feed rows are text-only; portfolio media lives on profiles as external URLs.
  • "Find groups" → Screen 03. "Create my profile" → Screen 02 (requires sign-in via the external identity provider).
  • Names and places are sample data.
