Prototype notes — Screen 05 · US-04 / UC-04

  • Submit: POST /groups/{groupId}/members (addGroupMember) with AddMemberRequest: userId*, skillRole*.
  • 200 → GroupListingResponse; the new member has memberRole MEMBER.
  • 409 → duplicate member or filled role (ROLE_SLOT_FULL) shown at the top of the form; the stale role is marked filled.
  • 403 → non-owner; 404 → unknown group or user; 400 → missing field; 401 → sign-in notice.
  • Reached from the owner actions on Screen 04. The user ID is the one returned on Screen 02.
  • Message text comes from the Problem body (title, detail, code).
