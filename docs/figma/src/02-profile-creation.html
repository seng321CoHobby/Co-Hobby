Prototype notes — Screen 02 · US-01 / UC-01

  • Categories and roles: GET /tags → TagCategory[] (category, roles). Public.
  • Submit: POST /profiles with NewProfile: displayName*, primaryCategory*, skillRole*, bio, mediaUrls (URI list).
  • 400 → message built from the Problem body (title, detail, code) and the invalid field highlighted.
  • 401 → sign-in notice; sign-in happens at the external identity provider.
  • 201 → ProfileResponse; the returned userId is what an owner enters on Screen 05.
  • Media files are never uploaded here; only links to external hosts are stored. Names are sample data.
