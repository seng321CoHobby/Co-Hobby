Prototype notes — Screen 04 · US-03 / UC-03 (owner actions lead to US-04, US-05)

  • Data: the selected GroupListingResponse from GET /groups; the API has no single-group endpoint.
  • Roles = creatorSkillRole (filled by the OWNER) + neededRoles; a needed role is filled when a member's skillRole matches it.
  • Members show memberRole and skillRole; GroupMember carries only userId, so no names are shown.
  • There is no self-join or apply operation in the first release; the hobbyist shares their userId with the owner outside the platform.
  • "Assign a member" → Screen 05. "Start the group project" → Screen 06.
  • Owner-only buttons are hidden for other users; the API still enforces 403.
