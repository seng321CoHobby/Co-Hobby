Prototype notes — Screen 06 · US-05, US-06 / UC-05

  • Create: POST /projects (createProject) with groupId*, title*, description → 201, progressStage PLANNING, isShared false.
  • Advance: PATCH /projects/{projectId}/progress with the next progressStage only. The UI offers just the next stage.
  • 409 on skipped or backward stage (for example a stale tab) → message and reload.
  • 403 non-owner, 404 unknown group/project, 400 missing title or unknown stage, 401 sign-in notice.
  • "Share project" opens Screen 07; it can succeed only in COMPLETED.
  • Stage order: PLANNING → WEEK_1 → WEEK_2 → COMPLETED (terminal).
