# Co-Hobby

**Course:** SENG 321  
**Team Number:** 19  
**Project Name:** Co-Hobby

Co-Hobby helps solo hobbyists find groups with suitable skill vacancies and helps formed groups track and share their projects through sequential milestones.

## Repository workflow

Work follows the lightweight Git-Flow model in [docs/04-git-flow-policy.md](docs/04-git-flow-policy.md): feature branches (`feature/<issue>-<short-name>`) merge into `develop` through reviewed pull requests, and assessed versions are released to `main` with a sprint tag.
